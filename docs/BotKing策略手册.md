## 四、v1.1 核心优化（相比v1.0）

### 优化1：网格引擎止损参数分离

**问题**：v1.0网格和趋势引擎共用12%止损，但网格用0.6%×4格=2.4%利润，需要83%+胜率才回正。

**v1.1解决方案**：

| 参数 | v1.0 | v1.1优化 | 说明 |
|------|------|---------|------|
| 每格利润 | 0.6% | **0.4%** | 收窄，提高胜率 |
| 高波动格距 | 1.0% | **0.6%** | 收窄 |
| 网格止损 | 12% | **8%** | 收窄，减少单次亏损 |
| TS激活 | 6%浮盈 | **4%浮盈** | 更早锁利 |
| 网格区间 | ±6% | **±4%** | 收窄 |

**期望值改变**：需要3次赢才能弥补1次止损 → **75%胜率=正期望**（v1.0需要83%）

### 优化2：API限速与熔断机制

**问题**：币安API有1200请求/分钟限制，高频调用可能触发限速。

**v1.1解决方案**：
- 60秒窗口内最多900请求（留300余量）
- 连续50次API失败 → 触发熔断，暂停120秒
- 所有API调用前检查限速，超限自动等待

### 优化3：多币关联性敞口检查

**问题**：同时持有ETH+BNB+SOL，熊市时高度相关可能同时暴跌。

**v1.1解决方案**：
- 追踪所有持仓的关联性总暴露（BTC=1.0基准）
- BTC熊市时，高度相关币（ETH/BNB）仓位×0.3
- 已持有高相关币时，新开仓再降50%
- 每次开仓前评估关联性总敞口

## 五、双引擎说明

### 引擎1：网格引擎（GridEngine）

**什么时候用？**
- RANGE_BOUND（震荡市）
- VOLATILE_OVERSOLD（超卖反弹）

**原理：**
把资金分成N格，每格等距分布。价格跌到某格就买，涨回来就卖，反复收割。

**v1.1网格参数（ATR自适应）**：

| 市场波动 | 格数 | 每格利润 | 止损 |
|---------|------|---------|------|
| 高ATR>5% | 2格 | 0.6% | -8% |
| 中ATR 2-5% | 4格 | 0.4% | -8% |
| 低ATR<2% | 6格 | 0.3% | -8% |

**追踪止损（TS）**：
- 浮盈 > 4% 时激活（原6%）
- 价格从最高点回落 2.5% → 触发TS，全格卖出

**分批建仓：**
- 第一批：先开1-2格（根据资金量）
- 第二批：止盈确认后，等5分钟再开下一批

---

### 引擎2：趋势引擎（TrendEngine）

**什么时候用？**
- TREND_UP（上升趋势）
- VOLATILE_OVERSOLD（超卖反弹后可能转趋势）

**买入信号：**
- EMA20(1D+4H+1H) 三周期全部向上
- RSI 1H > 40

**止盈分两阶段：**

| 阶段 | 条件 | 操作 | 剩余仓位 |
|------|------|------|---------|
| TP1 | 浮盈 ≥ +15% | 卖 50% 仓位 | 50% |
| TP2 | 浮盈 ≥ +25% | 卖 100% 仓位 | 0% |

**趋势追踪止损（TS）：**
- 浮盈 > 15% 后激活
- 价格回落 5% → 触发TS，全仓卖出

**止损：**
- 固定 -12% 止损
- 趋势破坏立即止损

## 八、利润分层

```
利润 = 100%
├── 50% 锁定 → 保留不动，不投入市场
├── 30% 复利 → 自动投入下一格/下一仓
└── 20% buffer → 覆盖手续费、滑点
```

**提盈机制**：
- 触发条件：余额 ≥ 历史最高 × 120%
- 最低门槛：利润 ≥ $5
- 提取比例：利润的 50%

## 九、完整交易流程

### 开盘流程（BotKing自动执行）

```
① 扫描6个币种，检测市场模式
② 检查关联性总敞口
③ 按 score 排序买入信号
④ 分配资金开仓（关联性降仓）
⑤ 每20秒检查止盈/止损/TS
⑥ 每180秒重新扫描市场模式
⑦ 仓位平仓后自动清理引擎，可重新开仓
```

### 平仓信号

```
自动止盈（网格）：
  - 价格触及目标价 → 卖出该格

自动止损（网格）：
  - 价格触及SL价（-8%）→ 卖出该格

追踪止损（网格）：
  - 浮盈>4%激活 → 从高点回落2.5% → 卖出

市场信号平仓：
  - VOL_OVERBOUGHT → 全部止盈
  - TREND_DOWN → 网格全平
  - CRISIS → 全部暂停

手动平仓：
  - 用户在币安APP手动卖出 → BotKing识别并释放资金
```
