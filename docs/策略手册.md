## 二、指标计算公式

### 2.1 RSI（相对强弱指数）
```
RSI = 100 - 100/(1 + RS)
RS = 平均涨幅 / 平均跌幅（14周期）
```

### 2.2 StochRSI（随机RSI）
```
RSI_values = [RSI(i) for i in range(period, len(prices)+1)]
lowest = min(RSI_values[-smooth_k:])
highest = max(RSI_values[-smooth_k:])
StochRSI_K = (RSI[-1] - lowest) / (highest - lowest) × 100
StochRSI_D = SMA(StochRSI_K, smooth_d)
```

### 2.3 EMA（指数移动平均）
```
EMA = prices[0]的SMA + Σ(prices[i] × 2/(n+1) × (1 - 2/(n+1))^(i-1))
简化：EMA = prices[:n]的SMA作为初值
     EMA = price × 2/(n+1) + prev_EMA × (1 - 2/(n+1))
```

### 2.4 ADX（平均趋向指数）
```
TR = max(H-L, |H-PrevClose|, |L-PrevClose|)
+DM = max(H-PrevH, 0) if (H-PrevH) > (PrevL-L) else 0
-DM = max(PrevL-L, 0) if (PrevL-L) > (H-PrevH) else 0
+DMI = (+DM的14日均值 / TR的14日均值) × 100
-DMI = (-DM的14日均值 / TR的14日均值) × 100
DX = |+DMI - (-DMI)| / (+DMI + -DMI) × 100
ADX = DX的14日均值
```

### 2.5 ATR（平均真实波幅）
```
TR = max(H-L, |H-PrevClose|, |L-PrevClose|)
ATR = TR的14日均值
```

## 三、趋势判断

### 3.1 EMA20趋势（核心）
```python
ema20 = calc_ema(prices, 20)
ema20_prev = calc_ema(prices[:-N], 20)  # N=4 for 4H, N=1 for 1H
trend_up = (cur > ema20) and (ema20 > ema20_prev)
```

long_score = 0

## 五、开仓逻辑

```python
def get_signal(symbol):
    # 获取多周期数据
    k4h = get_klines(symbol, "4h", 60)
    k1h = get_klines(symbol, "1h", 100)
    k15m = get_klines(symbol, "15m", 100)
    
    # 指标计算
    r4 = calc_rsi(c4h, 14)
    r1 = calc_rsi(c1h, 14)
    r15 = calc_rsi(c15m, 14)
    sk15, sd15 = calc_stoch_rsi(c15m, 14, 3, 3)
    sk1, sd1 = calc_stoch_rsi(c1h, 14, 3, 3)
    
    # 趋势判断
    trend_up = (cur > ema1h_20) and (ema1h_20 > ema1h_20_prev)
    
    # 市场环境
    adx_val, adx_bullish = calc_adx(k1h, 14)
    market_trending = adx_val >= 25
    market_weak = adx_val < 20
    
    # ===== 信号评分 =====
    long_ready = (r1 < 40 or (r1 < 45 and (sk15 < 20 or sk1 < 20))) \
                 and trend_up and r4 < 60 and not market_weak
    
    short_ready = (r1 > 35 and r4 >= 15 and r4 < 60) \
                  and not trend_up and not market_weak
    
    # ===== 逆势信号 =====
    ema_deviation = abs(cur - ema1h_20) / ema1h_20 * 100
    
    if r1 < 40 and ema_deviation > 0.5 and not market_weak:
        ct_score = calc_counter_trend_score(...)
        if ct_score >= 6.5: return "LONG", ct_score
    
    if r1 > 60 and ema_deviation > 0.5 and r4 >= 15 and not market_weak:
        ct_score = calc_counter_trend_score(...)
        if ct_score >= 6.5: return "SHORT", ct_score
    
    # ===== 趋势信号 =====
    if long_score >= 6.5: return "LONG", long_score
    if short_score >= 6.5: return "SHORT", short_score
    
    return None, 0
```

## 六、仓位计算

### 6.1 单笔开仓数量
```python
qty = balance × RISK_PCT ÷ SL_PCT ÷ LEVER
    = balance × 10% ÷ 2% ÷ 20
```

示例：
- 余额 $39 → qty = 39 × 0.10 / 0.02 / 20 = 0.975 → 实际取0.001

### 6.2 总仓位计算（已修复）
```python
# ❌ 错误算法（按名义值）
total_exposure = Σ(amt × price)

# ✅ 正确算法（按保证金）
total_exposure = Σ(amt × price ÷ LEVER)
```

示例：
- BTC SHORT 0.001 @ $60,466 → 保证金 = 0.001 × 60466 ÷ 20 = $3.02
- ETH SHORT 0.008 @ $1,553 → 保证金 = 0.008 × 1553 ÷ 20 = $0.62
- 总保证金 = $3.64，余额$39，占比9.3% ✅

### 6.3 仓位限制
| 类型 | 限制 |
|------|------|
| 单标上限 | ≤余额30% |
| 总仓位上限 | ≤余额150%（按保证金） |

## 十、完整交易流程

```
1. 获取多周期K线（4H/1H/15M）
2. 计算指标：RSI, StochRSI, EMA20, ADX, ATR
3. 趋势判断：EMA20多周期确认
4. 市场环境过滤：ADX门槛
5. 信号评分：≥6.5分触发
6. 风控检查：
   - 余额是否足够
   - 单标仓位是否超限
   - 总仓位是否超限（按保证金）
   - 是否在熔断冷却期
7. 开仓：市价单
8. 状态追踪：
   - TP1触发 → 出半场 + 追踪止损
   - TP2触发 → 出清剩余
   - 止损触发 → 记录连亏 + 熔断检查
9. 循环回到步骤1
```
