## 1. 交易路径工作流

```
数据采集 → 信号计算 → 趋势判断 → 信号评分 → 开仓决策 → 订单执行 → 状态更新
    ↓           ↓           ↓           ↓           ↓           ↓           ↓
获取K线   计算RSI    多周期EMA    评分≥6.5    检查持仓      市价开仓    写状态文件
  ↓      /Stoch   趋势确认     是→信号      无反向仓     写日志       写PM2日志
计算ATR   /ADX    /成交量      否→跳过      余额≥3U     冷却15s     下一周期
```

### 完整流程时序

```
T+0s   获取4H/1H/15M K线数据
T+1s   计算RSI(14)、StochRSI、EMA20、ATR
T+2s   计算ADX市场环境判断
T+3s   多周期趋势评分
T+4s   逆势/震荡模式检测
T+5s   综合评分 ≥6.5 → 确定信号(LONG/SHORT)
T+6s   检查反向持仓(防止逆向开仓)
T+7s   检查余额是否足够
T+8s   执行市价开仓
T+9s   写入状态文件(st_xxx.json)
T+10s  等待15秒进入下一周期
```

## 2. 信号计算明细

### 2.1 数据源

| 数据 | 周期 | 用途 |
|------|------|------|
| K线 | 4h/1h/15m | RSI、EMA、StochRSI计算 |
| RSI | 4H/1H/15M | 超买超卖判断 |
| StochRSI | 15M/1H | 中性区极值捕捉 |
| ATR | 15M(14) | 止损/仓位计算 |
| EMA20 | 4H/1H/15M | 趋势方向判断 |
| ADX | 14周期 | 市场强度判断 |
| 成交量 | 15M | 放量确认 |

### 2.2 信号评分体系

```
做多评分(long_score, ≥6.5触发LONG信号):
  - R1<35         → +1.0
  - R1<40         → +0.5  (放宽区)
  - R4<50         → +1.0
  - R15<40        → +1.0
  - 趋势向上       → +1.0
  - StochK15<20   → +2.0
  - StochK1<20    → +1.0
  - 放宽区无Stoch极端 → -0.5
  - 底背离        → +2.0
  - 成交量V>1.5x  → +1.0
  - EMA确认       → +1.5

做空评分(short_score, ≥6.5触发SHORT信号):
  - R1>65         → +1.0
  - R1>60         → +0.5  (放宽区)
  - R4>50         → +1.0
  - R15>60        → +1.0
  - 趋势向下       → +1.0
  - StochK15>80   → +2.0
  - StochK1>80    → +1.0
  - 放宽区无Stoch极端 → -0.5
  - 顶背离        → +2.0
  - 成交量V>1.5x  → +1.0
  - EMA确认       → +1.5
```

### 2.3 趋势ready条件

```python
做多准备(long_ready) = 同时满足:
  - 价格 > EMA1H20
  - EMA1H20向上
  - RSI1H < 45
  - 4H趋势向上
  - R4 < 60
  - (市场趋势强 OR RSI1H < 35)
  - ADX不是弱势市场

做空准备(short_ready) = 同时满足:
  - 价格 < EMA1H20
  - EMA1H20向下
  - RSI1H > 50
  - 4H趋势向下
  - R4 ≥ 15 (超卖保护，不允许在R4<15时做空)
  - R4 < 60
  - (市场趋势强 OR RSI1H > 55)
  - ADX不是弱势市场
```

### 2.4 逆势/震荡模式

当价格在EMA20±2%内震荡时，触发逆势信号：

```python
逆势做多(评分≥6.5):
  - RSI1H < 25 (极端超卖) → +2.0
  - RSI1H < 30           → +1.5
  - RSI1H < 35           → +1.0
  - 价格偏离EMA>1.5%     → +1.5
  - 价格偏离EMA>1.0%     → +1.0
  - StochK15 < 20        → +2.0
  - StochK1 < 20         → +1.0
  - 底背离               → +1.5

逆势做空(评分≥6.5):
  - RSI1H > 75 (极端超买) → +2.0
  - RSI1H > 70           → +1.5
  - RSI1H > 65           → +1.0
  - 价格偏离EMA>1.5%     → +1.5
  - 价格偏离EMA>1.0%     → +1.0
  - StochK15 > 80        → +2.0
  - StochK1 > 80         → +1.0
  - 顶背离               → +1.5
```

## 3. 订单执行流程

### 3.1 开仓流程

```
输入: symbol, direction(LONG/SHORT), qty
1. 检查余额 balance > 3 USDT (MIN_BAL)
2. 计算仓位: qty = balance × 10% ÷ 1.5% ÷ 20x
3. 发送市价单:
   POST /fapi/v1/order
   symbol=BTCUSDT
   side=BUY(做多)/SELL(做空)
   positionSide=LONG/SHORT
   type=MARKET
   quantity=0.001 (BTC) / 0.01 (ETH)
4. 记录返回orderId
5. 写入状态文件
```

### 3.2 仓位管理逻辑

```
持仓中(每15秒检查):
  ├── 读取持仓数据
  ├── 计算浮盈浮亏 pnl%
  │
  ├── LONG持仓:
  │     ├── TP1触发 (浮盈≥2%):
  │     │     出半仓
  │     │     标记tp1_done=True
  │     │
  │     ├── TP2触发 (浮盈≥4%):
  │     │     追踪止损: best_high × (1-0.8%)
  │     │     若现价≤追踪止损 → 出清剩余半仓
  │     │     标记tp2_done=True, loss_streak_count--
  │     │
  │     └── 无TP → 日志输出浮亏/浮盈
  │
  └── SHORT持仓:
        ├── TP1触发 (浮盈≥2%):
        │     出半仓
        │
        └── TP2触发 (浮盈≥4%):
              追踪止损: best_low × (1+0.8%)
              若现价≥追踪止损 → 出清剩余半仓
```

### 3.3 关键参数

| 参数 | 值 | 说明 |
|------|------|------|
| LEVER | 20x | 杠杆倍数 |
| RISK_PCT | 10% | 单笔风险金比例(余额的10%) |
| SL_ATR_MULT | 1.5 | ATR止损倍数 |
| TP1_PCT | 2% | 止盈1触发点 |
| TP2_TRIGGER | 4% | 止盈2触发点 |
| TP2_BUFFER | 0.8% | 追踪止盈回撤幅度 |
| MIN_BAL | 3 USDT | 开仓最低余额 |
| OPEN_COOLDOWN | 0秒 | 开仓冷却(已取消) |

## 4. 风控要点

### 4.1 自动熔断机制

```python
LOSS_STREAK_LIMIT = 3    # 连续3次亏损触发熔断
LOSS_STREAK_PAUSE = 15*60  # 熔断15分钟

逻辑:
  if 连续亏损≥3次:
    sleep(15分钟), 禁止开仓
  else:
    正常交易
```

### 4.2 超卖保护

- R4(4H RSI) < 15 时，**禁止做空**（价格可能瞬间反弹）
- 做空必须同时满足: R4 ≥ 15 且 R4 < 60

### 4.3 反向持仓屏蔽

- 已有SHORT持仓时，禁止LONG开仓
- 已有LONG持仓时，禁止SHORT开仓
- 防止多空对锁

### 4.4 手动平仓同步

状态文件中记录 `closed` 时间，下次扫描检测到交易所已平仓但状态文件未更新时，自动同步。

## 5. 状态文件说明

| 文件 | 用途 |
|------|------|
| `st_btc_long.json` | BTC做多状态 |
| `st_btc_short.json` | BTC做空状态 |
| `st_eth_long.json` | ETH做多状态 |
| `st_eth_short.json` | ETH做空状态 |

### 状态文件字段

```json
{
  "pos": "SHORT",        // 持仓方向
  "entry": 73420.3,      // 开仓价
  "qty": 0.001,          // 数量
  "sl": 73738.34,        // 软止损(状态文件记录，非交易所单)
  "atr": 318.04,         // ATR值
  "best": 72514.2,       // 最优价(追踪止盈用)
  "opened": 1779987619,  // 开仓时间戳
  "tp1_done": false,     // TP1是否已触发
  "tp2_done": false,     // TP2是否已触发
  "last": null           // 最后操作
}
```
