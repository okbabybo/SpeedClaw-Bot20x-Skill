## 工作流程

```
采集K线(1H/4H/15m) → RSI/StochRSI/EMA/ATR/ADX/MACD/布林带
    ↓
ADX市场环境判断 → 趋势市场(>25) / 弱势(<20) / 震荡
    ↓
多周期趋势确认 → 强趋势模式(EMA共振放宽RSI到55) / 震荡模式(RSI<45)
    ↓
K线形态检测 (v5.9) + 流动性猎杀 + 支撑阻力强度
    ↓
主信号 ≥6.5? ─┬─ 是 → v5.10 RSI软门槛检查 → 开仓
    │         │
    └── 否 ───┘
    ↓
逆势模式检测 ── 触发 → 按逆势信号操作
    ↓
持仓管理：TP1半仓 → TP2追踪 → 手动平仓冷静期
    ↓
无信号 → 跳过，等待下一周期
```
