## 核心能力

### 1. 双币种交易

机器人同时监控 **BTC** 和 **ETH** 的永续合约市场：
- **BTCUSDT**：流动性最强，波动相对稳定
- **ETHUSDT**：波动更大，机会更多但风险也更高

两个币种独立运行，独立计算仓位和盈亏。

### 2. 多周期趋势确认

| 周期 | 用途 | 说明 |
|------|------|------|
| 4H | 主趋势判断 | 决定大方向（上涨/下跌/震荡） |
| 1H | 中期趋势确认 | 验证4H判断，避免逆势 |
| 15M | 精确入场点 | 寻找最佳入场时机 |

**趋势判断逻辑**：
- EMA20 > EMA50 → 向上
- EMA20 < EMA50 → 向下
- 趋势冲突时（4H向上但1H向下）→跳过信号，等待趋势一致

### 3. StochRSI 超买超卖捕捉

| 信号 | StochRSI | 含义 |
|------|----------|------|
| 超卖 | < 20 | 可能反弹，是做多信号 |
| 超买 | > 80 | 可能回调，是做空信号 |

StochRSI 结合作k线形态和RSI背离使用，提高信号准确性。

### 4. 趋势反转预警（v5.2新增）

机器人实时监控趋势变化，发现反转迹象时：
- 推送预警通知
- 记录趋势状态变化
- 避免在趋势转换时逆势开仓

### 5. 自动止损止盈

| 类型 | 规则 | 说明 |
|------|------|------|
| 止损 | 2%固定 | 触及即平仓，最大亏损控制 |
| 止盈1（TP1） | 2% | 先出一半，锁定利润 |
| 止盈2（TP2） | 4%触发 | 出清剩余仓位 |
| 追踪止盈 | 0.8%回撤 | 利润持续创新高后保护 |

## 信号系统详解

### 做多信号（触发门槛：6.5分）

| 加分项 | 条件 | 分数 |
|--------|------|------|
| RSI1H | < 40 | +1 |
| RSI4H | < 50 | +1 |
| RSI15M | < 40 | +1 |
| 趋势向上 | EMA多头排列 | +1 |
| StochRSI15M | < 20 | +2 |
| StochRSI1H | < 20 | +1 |
| RSI底背离 | 价格新低但RSI未新低 | +2 |

**做多逻辑**：RSI处于低位（超卖区域）+趋势向上 + StochRSI超卖 = 反弹概率高

### 做空信号（触发门槛：6.5分）

| 加分项 | 条件 | 分数 |
|--------|------|------|
| RSI1H | > 35 | +1 |
| RSI4H | ≥15 且 <60 | +1 |
| 趋势向下 | EMA空头排列 | +1 |
| StochRSI15M | > 80 | +2 |
| StochRSI1H | > 80 | +1 |
| RSI顶背离 | 价格新高但RSI未新高 | +2 |

**做空逻辑**：RSI处于高位（超买区域）+ 趋势向下 + StochRSI超买 = 回调概率高

### 逆势交易模式（v5.2新增）

当检测到极端超卖/超买时，机器人会在回调概率极高的位置**逆势开仓**：
- 条件：RSI1H < 30 或 RSI1H > 70 + 极端位置
- 目的：在趋势反转点抓住反弹机会
- 风险：比顺势交易风险更高

### 趋势冲突过滤（v5.2新增）

当4H和1H趋势矛盾时，机器人会跳过信号：
- 4H向上 + 1H向下 = 等待1H趋势反转
- 4H向下 + 1H向上 = 等待1H趋势反转

这样避免在震荡市中频繁被止损。

## 风险管理

### 仓位计算

```
单标仓位 = 余额 × 10% ÷ 1.5% ÷ 20x
```

| 余额 | 单标仓位（约） |
|------|----------------|
| $10 | $3.3 |
| $50 | $16.7 |
| $100 | $33.3 |

总仓位不超过余额的 150%（可同时开BTC+ETH）。

### 复利风控

| 参数 | 值 | 说明 |
|------|------|------|
| MAX_POS_PCT | 30% | 单标仓位上限 |
| MAX_TOTAL_EXPOSURE | 150% | 总仓位上限 |
| DRAWDOWN_PROTECT | 15% | 回撤15%减半仓 |
| RISK_DANGER | $20 | 危险区余额阈值 |

### 熔断机制

| 条件 | 动作 |
|------|------|
| 连亏3次 | 暂停15分钟 |
| 余额从高点回撤15% | 减半仓运行 |
| 余额低于$3 | 停止开仓 |
